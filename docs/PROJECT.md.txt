# CAMPUS SHARE

## Overview

Campus Share is a college project.

Students can rent useful items from other students inside the same college or hostel.

The objective is to create a clean, functional MVP within one day.

This is NOT intended to be a production startup.

---

# Objectives

Build a working website that demonstrates

- Authentication
- CRUD
- Firebase
- File Upload
- Search
- Responsive UI

while keeping implementation simple.

---

# Target Users

College Students

Examples

- Need a calculator before exam
- Need a lab coat
- Need a cricket bat
- Need a cycle
- Need an extension board
- Need a speaker
